# Week 1 - DevOps Foundations

## Goal
Build the foundation every DevOps engineer needs before touching any tools.
By the end of this week, students understand the culture, can navigate Linux,
use Git confidently, and have a working project on GitHub.

## Schedule

| Day | Topic | Key Outcome |
|-----|-------|-------------|
| Day 1 | What is DevOps? | Understand the culture and lifecycle |
| Day 2 | Linux Basics | Navigate and script in Linux |
| Day 3 | Git & Version Control | Use Git workflow and branching |
| Day 4 | Networking Basics | Understand how services talk to each other |
| Day 5 | Mini Project | Apply everything in a real workflow |

## Folder Structure
```
week1/
├── day1-devops-fundamentals/   # Culture, lifecycle, principles
├── day2-linux-basics/          # Commands, permissions, shell scripting
├── day3-git-version-control/   # Git workflow, branching, GitHub
├── day4-networking-basics/     # IP, DNS, ports, HTTP
└── day5-project/               # Hands-on mini project
```

## Tools Needed
- A Linux VM or WSL (Windows Subsystem for Linux)
- Git installed: https://git-scm.com
- A GitHub account: https://github.com
- A terminal (bash or zsh)

## Learning Objectives
By end of Week 1, students will be able to:
- [ ] Explain the DevOps culture and why it exists
- [ ] Navigate a Linux filesystem and manage files/permissions
- [ ] Write a basic bash script with variables, loops, and conditionals
- [ ] Use Git for version control with proper branching
- [ ] Open and merge a Pull Request on GitHub
- [ ] Explain how HTTP, DNS, and ports work
